# Armáda ČR v mapě a číslech

Přehled Armády České republiky z veřejných zdrojů, aktualizovaný každý týden: týdenní přehled, zahraniční mise, zbrojní průmysl, vojenská muzea a databáze VHÚ, počty vojáků a aktivních záloh, organizační struktura,
dislokace útvarů a vojenské újezdy na mapě, technika s fotkami, modernizační projekty, zákony,
strategické dokumenty a kontroverze. Včetně Hradní stráže a Vojenské police.

**Web:** https://sopikmi.github.io/Armada-CR/

- Data: `assets/data.js` (každé číslo se zdrojem a datem)
- Fotky: Wikimedia Commons, stažené do `foto/` workflowem `fetch-photos.yml`, s autorem a licencí
- Technické parametry: anglická Wikipedie (CC BY-SA 4.0), workflow `fetch-specs.yml`
- Mapa: Leaflet, vlastní podklad (Natural Earth, hranice krajů z siwekm/czech-geojson) a volitelně © OpenStreetMap
- Pravidla úprav: [AGENT.md](AGENT.md)
